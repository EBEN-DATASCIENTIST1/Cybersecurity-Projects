# Cybersecurity Projects — Phase 1

## Overview

This repository contains 15 hands-on cybersecurity projects developed as part of my cybersecurity learning journey. Each project focuses on a specific security concept, from reconnaissance and social engineering awareness to phishing detection, security monitoring, and incident response.

The goal of this phase is to develop practical Python programming skills, understand common attack techniques, explore defensive security mechanisms, and learn how to analyze and respond to potential security threats in controlled environments.

## Projects

### Project 1: OSINT and Passive Reconnaissance

Explores Open-Source Intelligence (OSINT) techniques to collect publicly available information about domains, DNS records, and IP addresses.

**Key skills:** Python, DNS analysis, reconnaissance, information gathering.

### Project 2: Email Harvesting

Demonstrates how email addresses can be extracted from sample HTML pages and authorized sources, highlighting the privacy risks associated with publicly exposed information.

**Key skills:** Python, HTML parsing, regular expressions, data extraction.

### Project 3: Phishing URL Detector

Analyzes URLs using heuristic rules to identify characteristics commonly associated with phishing links.

**Key skills:** URL parsing, feature analysis, Python, threat detection.

### Project 4: Vishing and Smishing Awareness

Explores voice-phishing (vishing) and SMS-phishing (smishing) through fictional scenarios that demonstrate common social engineering techniques.

**Key skills:** Social engineering awareness, threat identification, security education.

### Project 5: OSINT-Based Target Profile

Examines publicly available profile and repository information to demonstrate how exposed information can contribute to an individual's digital footprint.

**Key skills:** OSINT, GitHub API, JSON processing, risk assessment.

### Project 6: Spear-Phishing Awareness Training

Uses fictional targeted-phishing scenarios to identify manipulation techniques and explain defensive measures against deceptive emails.

**Key skills:** Email security, social engineering analysis, awareness training, incident prevention.

### Project 7: Password Attack and Rate-Limit Simulation

Simulates repeated login attempts against a local test application to demonstrate how failed-login monitoring and rate limiting can help protect authentication systems.

**Key skills:** Python, Flask, authentication security, rate limiting.

### Project 8: USB Drop Attack Simulation

Models the security risks associated with unknown USB devices in a controlled environment without executing a real malicious payload.

**Key skills:** Python, device-security awareness, risk assessment, defensive analysis.

### Project 9: Fake Profile Detection

Analyzes fictional social media profiles using heuristic indicators to identify potentially suspicious characteristics.

**Key skills:** Python, data analysis, rule-based detection, JSON.

### Project 10: Baiting and Watering-Hole Simulation

Uses a local honeypot-style application to simulate website visits and analyze logged activity, illustrating how suspicious interactions can be observed safely.

**Key skills:** Flask, HTTP requests, logging, event analysis.

### Project 11: Social Engineering Awareness Training

Implements an interactive quiz that evaluates awareness of social engineering techniques and produces results for review.

**Key skills:** Python, interactive applications, assessment, security awareness.

### Project 12: Machine Learning for Phishing Email Detection

Builds a machine learning classifier using a dataset of fictional emails to distinguish between phishing and legitimate messages.

**Key skills:** Python, pandas, scikit-learn, text classification, model evaluation.

### Project 13: SIEM Log Analysis

Processes sample security logs to identify events such as repeated failed logins and other potentially suspicious activities, then generates alerts for analysis.

**Key skills:** Log parsing, Python, event correlation, JSON, security monitoring.

### Project 14: Social Engineering Incident Response

Develops a simulated incident response workflow covering incident documentation, defensive recommendations, and response procedures.

**Key skills:** Incident analysis, response planning, documentation, risk mitigation.

### Project 15: Social Engineering Attack Chain Simulator

Combines selected security-learning modules into a single application covering passive reconnaissance, profile exposure review, heuristic URL analysis, awareness training, and incident response simulation.

**Key skills:** Python integration, modular programming, security analysis, defensive thinking.

## How the Projects Connect

These projects are related through a common cybersecurity workflow: understanding exposure, recognizing threats, detecting suspicious activity, and responding appropriately.

1. **Reconnaissance and exposure assessment — Projects 1, 2, and 5:** Explore how publicly available information can reveal potential risks.
2. **Social engineering and phishing awareness — Projects 3, 4, 6, and 11:** Examine deceptive URLs, messages, and manipulation techniques while developing prevention strategies.
3. **Application and device security — Projects 7, 8, 9, and 10:** Simulate authentication attacks, device-related risks, suspicious profiles, and website interactions in controlled environments.
4. **Detection and analysis — Projects 12 and 13:** Apply machine learning and log analysis to identify potential threats.
5. **Incident response and integration — Projects 14 and 15:** Organize defensive response procedures and integrate selected techniques into a unified simulation.

Together, these projects demonstrate how individual cybersecurity techniques can contribute to a broader defensive security process.

## Ethical and Safe Use

These projects are intended for educational and defensive cybersecurity learning.

- Perform testing only in local labs, on systems you own, or on systems for which you have explicit authorization.
- Use fictional datasets and sample scenarios where possible.
- Do not use reconnaissance, email collection, phishing, or password-testing techniques to target unauthorized systems or individuals.
- Protect credentials, personal information, and other sensitive data.
- Treat automated detection results as indicators for further investigation rather than definitive proof of malicious activity.
