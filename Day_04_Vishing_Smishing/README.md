# Day 4 — Vishing & Smishing Awareness Trainer

## Overview

This project generates cybersecurity awareness-training scenarios about vishing (voice phishing) and smishing (SMS phishing).

It demonstrates how attackers exploit authority, urgency, fear, and trust to manipulate people. The tool focuses on recognizing warning signs and practicing safe responses.

## Features

- Generate an IT support awareness scenario.
- Generate a banking awareness scenario.
- Generate a government impersonation awareness scenario.
- Explain psychological manipulation techniques.
- Identify warning signs of social engineering.
- Recommend safe responses.
- Save each scenario as a separate text report.

## Technologies Used

- Python
- pathlib

No external Python packages are required.

## Usage

Run the program from the project directory:

```bash
python main.py
```

Choose one of the three scenarios:

1. IT Support
2. Banking
3. Government

The generated scripts are saved in the `reports/` directory.

## Learning Objectives

- Understand vishing and smishing.
- Recognize authority, urgency, fear, and trust as manipulation techniques.
- Identify suspicious requests for confidential information.
- Learn to verify unexpected requests through independent official channels.
- Practice safe responses to suspected social engineering.

## Ethical Use

This project is intended for cybersecurity awareness and defensive training. Use the scenarios to educate participants, not to impersonate real organizations, collect credentials, or deceive people outside an authorized exercise.

## Limitations

The scenarios are educational examples. They do not contact people, send SMS messages, or make phone calls. They are not a real-world phishing detection system.
